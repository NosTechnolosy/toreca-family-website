# トレカfamily サイト更新 v0.3.0

## 追加・変更内容

- 買取表画像を最大5枚まで登録可能
- 登録済み画像の一覧表示
- 画像の追加、差し替え、削除
- 上下ボタンによる表示順の変更
- Webサイトで約5秒ごとの自動スライド
- 左右矢印、スマートフォンのスワイプ、インジケーターに対応
- マウスを乗せている間と拡大表示中は自動スライドを一時停止
- 画像をクリック・タップした際の拡大表示とスマートフォンのピンチ拡大
- 買取表右下のマスコットが画像と一緒にスライド
- 1枚のみの場合はスライド操作を停止
- アニメーション軽減設定に対応

## 注意事項

- 1枚あたり8MBまでです。
- Webサイトへの反映には数分かかる場合があります。
- 接続先と接続キーはv0.2.0から変更ありません。
