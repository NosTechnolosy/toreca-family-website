# トレカfamily サイト更新アプリ 導入手順

対象バージョン: 0.3.0
対応OS: Windows 10 / Windows 11（64bit）

## 1. インストール

1. 配布ページまたはUSBから `トレカfamily サイト更新_0.3.0_x64_ja-JP.msi` をPCへコピーします。
2. ダウンロードしたMSIをダブルクリックします。
3. Windowsが発行元の確認画面を表示した場合は、管理者から案内された正規ファイルであることと、下記SHA-256が一致することを確認してから進めます。
4. 画面の案内に従ってインストールします。

### SHA-256

```text
66EAA899E645DA35AA341965E6D96FB3B456D382CFAD73C739FB0E1206E88605
```

## 2. 初回の接続設定

1. 「トレカfamily サイト更新」を起動します。
2. 右上の「接続設定」を押します。
3. 接続先へ次のURLを入力します。

```text
https://toreca-family-update-api.syouta-hasisako.workers.dev
```

4. 接続キーは管理者から電話または対面で受け取り、入力します。
5. 「保存」を押し、右上の状態表示が緑になれば設定完了です。

接続キーはメール、チャット、メモ帳へ保存しないでください。アプリではWindows資格情報マネージャーへ安全に保存されます。

## 3. 初回確認

1. 最新の在庫CSVを選択します。
2. CSV読込件数、公開対象、除外件数を確認します。
3. 販売価格0円または在庫0の商品が除外されていることを確認します。
4. 内容が正しければ、更新ボタンを1回だけ押します。
5. 「在庫データを更新しました。」と表示されるまでアプリを閉じません。
6. 数分後、公開サイトの在庫確認ページで更新内容を確認します。

公開サイト:

```text
https://nostechnolosy.github.io/toreca-family-website/inventory.html
```

## 4. 利用できる更新機能

- 在庫CSVの更新
- 商品マスタCSVの更新（商品画像URL）
- 買取表画像を最大5枚まで追加・差し替え・削除・並び替え

詳しい操作方法は `STAFF_GUIDE.md` を確認してください。

## 5. エラーが表示された場合

- 更新ボタンを連打しないでください。
- 接続状態とインターネット接続を確認してください。
- 接続キーが正しくない場合は、管理者へ連絡してください。
- 更新に失敗しても、公開済みの正常なデータは維持されます。
- 誤った内容を更新した場合は、直前の正しいCSVまたは画像を選び直して再更新します。

## 6. アンインストール

Windowsの「設定」→「アプリ」→「インストールされているアプリ」から「トレカfamily サイト更新」を選び、アンインストールします。
