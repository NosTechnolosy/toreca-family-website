# トレカfamily サイト更新 v0.2.0

店舗スタッフ向けWindows更新アプリの配布版です。

## 主な機能

- 在庫CSVの読み込み、内容確認、公開サイトへの更新
- 在庫0または販売価格0円の商品を自動除外
- 商品マスタCSVから商品画像URLを更新
- 買取表画像と表示日を更新
- 接続キーをWindows資格情報マネージャーへ保存
- 通信失敗・更新競合・不正データ時に既存の公開内容を保護

## 配布ファイル

- `トレカfamily サイト更新_0.2.0_x64_ja-JP.msi`
- `PARTNER_INSTALL_GUIDE.md`
- `STAFF_GUIDE.md`
- `SHA256SUMS.txt`

## 注意事項

- Windows 10 / 11（64bit）向けです。
- コード署名証明書は未導入です。Windowsが発行元確認を表示する場合があります。
- 接続キーは配布ファイルに含まれていません。管理者から別経路で受け取ってください。
